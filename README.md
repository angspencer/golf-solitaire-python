# Golf Solitaire

A command-line implementation of Golf Solitaire built with Python.

## Overview

This project recreates the card game Golf Solitaire as an interactive command-line game. The program creates and shuffles a standard deck, organizes cards into a seven-column game board, tracks the waste pile, and checks whether moves are valid.

## Features

- Interactive command-line gameplay
- Seven-column card layout
- Standard 52-card deck
- Randomized deck shuffling
- Valid-move checking
- Win and quit conditions
- Card and deck management

## Concepts Used

- Python
- Object-oriented programming
- Classes and objects
- Functions
- Lists and nested lists
- Loops and conditionals
- User input
- Game-state management
